# Battrochtek Canonical Corpus v15

This version replaces “grid arrays as the musical source” with a universal canonical event corpus.

- 213 canonical archetypes.
- 213 canonical JSON scores.
- 213 Standard MIDI Files.
- 960 PPQ timebase.
- Semantic articulations, limb assignment, event roles, velocity classes, provenance, and validation state.
- One compiled Battrochtek Curated library with one memory per canonical groove.
- Zero exact canonical/grid collisions after compilation.

See `musicology/CANONICAL-GROOVE-SPEC.md` and `musicology/canonical-corpus-index.json`.

Important: all 213 entries are playable, but not all have the same scholarly status. The corpus deliberately marks Battrochtek-created pedagogical adaptations as `pedagogical-adaptation-needs-review`; these should be progressively upgraded through literature/transcription review rather than silently treated as authoritative transcriptions.
