# FEEL v22 — Auto Orchestration explicite

- Auto Orchestration (`shuffle`) utilise désormais un intervalle explicite de 2, 4, 8 ou 16 boucles.
- Valeur par défaut : 4 boucles.
- À chaque échéance, une orchestration différente est choisie ; la grammaire musicale ne décide que de la destination, plus du moment du changement.
- Le paramètre d'intervalle reste réglable même lorsque `shuffle` est désactivé.
- Les textes FEEL/ORCHESTRATION FR/EN/ES ont été repris. En français, les formulations littérales comme « main de time » ont été remplacées par du vocabulaire naturel de batterie.
- Tout changement de mémoire continue de fermer FEEL, y compris via Chain.
- Cache PWA : v68.
