# Battrochtek Samples — v28

## Imported acoustic/world libraries

- **Jazz Club** — 128 WAV from `ferrosintesis-samples-drumkit 0.1.0`, a browser-oriented CC0 selection derived from Virtuosity Drums. Velocity layers, round robins, closed/open/pedal hi-hat, side-stick, ride bow/bell, kick, snare and toms.
- **Vintage Rock** — 104 browser-optimized WAV selected from Big Rusty Drums 1.100 (CC0). Close-mic set, four representative velocity layers and two round robins per articulation: kick, snare hit/side-stick/rimshot, HH closed/open/pedal, ride bow/bell, crash and three tom ranges.
- **World Percussion** — 177 VCSL CC0 WAV imported from the supplied Battrochtek subset. Includes hand percussion and idiophones; the original source paths are retained in the manifest.

All imported files are converted/copied to mono PCM16 44.1 kHz WAV where required. SHA-256, source collection, source path and license are stored in Manifest v2/provenance. Legacy v27 samples remain available.
